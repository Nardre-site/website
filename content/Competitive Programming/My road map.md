# Competitive Programming 4 
I started reading Competitive Programming 4 by Steven Halim and Felix Halim.
I learned most of things here:
- Data Structures 
	 1) Linear DS (Array, Special Sorting, Bitmask, Big Integer, Linked list, Stack)
	 2) Non linear DS (Binary heap (Priority Queue), Hash table, Balance Binary Search Tree)
	 3) Self DS (Graph, Union-find, Fenwick Tree, Segment Tree)
- Problem Solving Paradigms
	1) Complete Search
	2) Divide and Conquer (binary / ternary search, Divide and Conquer)
	3) Greedy
	4) Dynamic Programming
- Graph
	1) Graph Traversal (DFS, BFS, Connected Components, Flood Fill, Topological Sort, Bipartite Graph Check, Cycle Check, Articulation Points and Bridges, Strongly Connected Components)
	2) Minimum Spanning Tree (Kruskal, Prim)
	3) Single source paths (BFS, Dijkstra, Bellman-Ford)
	4) All pairs shortest paths (Floyd warshall)
	5) Special Graphs (Directed Acyclic, Tree, Bipartite, Eulerian)
- Mathematics
	1) Number Theory (Prime Numbers, Prime factors, Sieve, GCD, LCM, factorial, modular arithmetic)
	2) Combinatorics (Fibonacci Numbers, Binomial Coefficients, Catalan Numbers)
	3) Game Theory
I Didn't finished the 2nd book.
